Install guide

From download to first run, including what Windows will say about new software and how to check that your file is the real one.

Download

Open the Download page and choose the web installer. The browser may say the file is not commonly downloaded: choose Keep. That message means few people have downloaded it yet, not that something is wrong with it.

Windows protected your PC

When you run a new program that is not code signed, Microsoft Defender SmartScreen shows a blue window titled Windows protected your PC. It means Windows does not know this file yet. It does not mean a virus was found.

Check the checksum first (next step). Then click More info, check that the file name is the one you downloaded, and click Run anyway.

PQ-SSE Desktop is not code signed today. Signing would show a publisher name instead of Unknown publisher; it would not make the warning disappear on the first day either, because SmartScreen also waits until a file has been seen many times.

Check the file before running it

Open PowerShell in your Downloads folder (in File Explorer: right-click the folder background, Open in Terminal) and run:

Get-FileHash -Algorithm SHA256 .\PQ-SSE-Web-Setup.exe

Compare the Hash it prints with the SHA-256 for the same file on the Download page. Capital or small letters do not matter. If every character matches, the file is exactly the one that was published. If not, delete it and download it again.

Or use the Verify a download page: it computes the checksum in your browser, without uploading the file.

Install

The installer asks no admin password: it installs for your Windows account only, into your user folder. Read the welcome page, then choose Install. The web installer shows what it downloads and checks each file before running it.

First run

PQ-SSE Desktop first asks how you will use it. Local demo runs everything on this PC: the cloud part starts as a second program and listens on 127.0.0.1 only, so Windows does not ask for a firewall permission. Data owner and Receiver connect to a cloud server on another computer (the server program is a separate download). The guided lesson, Journey, always runs on a practice copy on this PC, so your own data is never touched.

Where your data is

Your keys, settings and documents are stored in %LOCALAPPDATA%\PQ-SSE-Desktop, separate from the program. Keys are kept encrypted with your passphrase. Installing, updating and uninstalling do not delete this folder.

Uninstall

Windows Settings, Apps, Installed apps, PQ-SSE Desktop, Uninstall. The uninstaller asks before touching your data and keeps it by default. To remove your data too, delete %LOCALAPPDATA%\PQ-SSE-Desktop afterwards.

Update

In the app, open About and choose Check for updates. It asks this site for the signed file list only when you click, never by itself. A new version installs over the old one and keeps your data.

Troubleshooting

The web installer says it has no connection

It talks only to this site and to GitHub, over HTTPS. A company proxy or filter may block it. Download the full installer from the Download page instead: it needs no connection while installing.

An antivirus program blocks or removes the file

New unsigned programs are sometimes flagged by mistake. Check the checksum first. If it matches, report the false alert to the antivirus maker (for Microsoft Defender: microsoft.com/wdsi/filesubmission) and restore the file. If it does not match, delete it.

The GPU build says the GPU path is off

The NVIDIA driver is older than the minimum, or the Windows user name contains letters outside plain English, which NVIDIA's compiler cannot handle. Update the driver from nvidia.com. Everything keeps working on the normal processor.
