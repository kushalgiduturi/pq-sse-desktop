Verify a download

Check that a file you downloaded is exactly the one that was published. The checksum is computed here, in your browser. The file is never uploaded.

This check needs JavaScript. Without it, use PowerShell and compare with the Download page, as the install guide shows. Install guide.

The file stays on your PC. Large files take a few seconds.
64 characters, letters a to f and digits. Capital or small letters do not matter.
