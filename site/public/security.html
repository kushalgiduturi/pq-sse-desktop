Security and privacy

What PQ-SSE Desktop stores, what leaves your PC, and exactly what the checks on the downloads do and do not prove.

What the app stores, and where

  • Everything is in %LOCALAPPDATA%\PQ-SSE-Desktop on your PC: settings, logs, the practice data and your own data.
  • Private keys are stored encrypted with your passphrase. They are never written to a log and never shown.
  • The cloud part is a second program on the same PC. Its database holds only locked documents and index entries; the smoke test scans it for plaintext on every build.

What leaves your PC

  • Nothing, by itself. The app does not phone home, has no telemetry and sends no crash reports.
  • Only what you start: a download from this site, or Check for updates in About, which reads the signed file list from this site once. You can hide that menu item in the settings.
  • This website sets no cookies, runs no analytics and loads nothing from other sites. Fonts and pictures are served from here.

How far you can trust a download

What a checksum proves

A SHA-256 checksum compared with the one on this site proves the file was not damaged or swapped on the way, as long as the checksum itself is genuine. If someone controlled both this site and the files, a matching checksum would prove nothing.

The signed file list

The file list (latest.json) and every package carry a signature made with a private key that is not in the code repository: the maintainer keeps it, and the release workflow can use it only as an encrypted GitHub Actions secret. The web installer has the matching public key built in, and refuses a list or a file whose signature does not match. Someone who changes the files or the list without that key is caught; someone who steals the key is not.

Two places

The checksums are published here and in the GitHub release notes. The site and the files are on different GitHub hosts, but GitHub runs both, so this is a weak second source.

Not code signed

None of this is Windows code signing. Windows names the publisher as unknown and SmartScreen may warn. Code signing would add a publisher name that a certificate authority checked; it is not set up today.

Code signing, researched

Azure Artifact Signing

Microsoft's signing service, about 9.99 US dollars a month. Microsoft answers from 2026 say individuals are accepted only in the USA and Canada. Not verified on an official eligibility page.

OV or EV certificate

A certificate from a commercial authority, a few hundred US dollars a year, with the key on a hardware token or in a cloud store. Microsoft says EV no longer removes the SmartScreen warning at once. Prices not verified with sellers.

SignPath Foundation

Free signing for open-source projects with a public repository and an OSI license; the certificate names SignPath Foundation as the publisher. Whether this project would be accepted is not verified.

Report a problem

  • A security problem in the app or the website: open a private security advisory on GitHub (Security tab of the repository, Report a vulnerability). Please do not open a public issue for it.
  • A false antivirus alert: check the checksum first, then report it to the antivirus maker (for Microsoft Defender: microsoft.com/wdsi/filesubmission) and, if you like, open an issue on GitHub so others know.
