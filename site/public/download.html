Which one do I pick?

  • Web installerSmall. It reads the signed file list from this site, downloads the right package for your PC, checks it, and installs it. Pick this one unless you have a reason not to.
  • Full installerEverything in one file. Works offline after downloading, and on PCs where the web installer is blocked. Standard runs everywhere; GPU is for PCs with an NVIDIA graphics chip.
  • Portable zipNo installation. Unzip it into a folder and run PQ-SSE-Desktop.exe. Nothing is added to the Start menu, and updates are up to you.
  • Standard or GPUThe GPU build can use an NVIDIA graphics chip to speed up one step, building a large index. Everything else, including all post-quantum work, runs on the normal processor in both builds. If unsure, pick Standard.

Requirements

  • Windows 10 version 1809 or newer, or Windows 11, 64-bit.
  • About 220 MB of disk space for the Standard build and about 420 MB for the GPU build.
  • No admin rights: it installs for your Windows account only.
  • GPU build only: an NVIDIA graphics chip and driver 528.33 or newer. The CUDA Toolkit is not needed. With an older driver or no NVIDIA chip, the GPU build runs on the normal processor and says so.

NVIDIA lists 525.60 as the minimum driver for this CUDA version on Linux; on Windows it is 528.33, which is the figure that applies here.

About trust

The files are not code signed, so Windows may warn before running them. The install guide explains the warning and how to check a file before you run it. The security page explains what the checksums and the signed file list do and do not prove. Install guide, Security and privacy.
